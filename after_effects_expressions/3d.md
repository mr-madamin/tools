# 3D

## Orientation

### Point a layer at another layer

Aims a 3D layer so it continuously faces a target — a light or camera tracking a null, or a card facing a moving object. Apply to Orientation, not Rotation, on a 3D layer.

```js
lookAt(transform.position, thisComp.layer("Target").transform.position)
```

### Billboard a layer to always face the active camera

Keeps a flat 3D layer facing the camera no matter how the camera moves — common for particle-like sprites or labels placed inside a 3D scene.

```js
lookAt(transform.position, thisComp.activeCamera.transform.position)
```

## Space conversion

### Converting between layer, comp, and world space

`toComp()`/`fromComp()` convert a point to/from the comp's 2D pixel space; `toWorld()`/`fromWorld()` convert to/from world space, ignoring the layer's own parenting. Needed whenever 2D UI elements and 3D layers, or layers in different parent hierarchies, have to interact.

```js
// this layer's anchor point, in the comp's 2D pixel space
toComp([0, 0, 0])
```

```js
// this layer's position in world space, ignoring its own parent
toWorld([0, 0, 0])
```

## Orbiting

### Orbit a camera around a null

Drives a camera's position in a circle around a target, with radius and speed on sliders — avoids hand-keying the orbit path. Apply this to the camera's Position, and set its Point of Interest to `target` directly so it stays aimed at the center.

```js
target = thisComp.layer("Orbit Target").transform.position;
radius = effect("Radius")("Slider");
speed = effect("Speed")("Slider"); // degrees per second
angle = time * speed * Math.PI / 180;
target + [Math.cos(angle) * radius, 0, Math.sin(angle) * radius]
```
